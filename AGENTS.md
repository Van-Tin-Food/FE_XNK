# Frontend Working Rules

Before making any change in this repository, read and follow:

- `.claude/docs/frontend-rules.md` (committed copy; `.codex/skills/xnk-frontend/SKILL.md` is git-ignored and may be missing or outdated)
- `CLAUDE.md` for project commands, document-workflow pitfalls, and what must not be done without explicit approval.

The rules file is the source of truth for frontend RBAC UI, translations, API contracts, loading/error states, pagination, responsive design, email workflows, and verification. Every new visible feature must have permission handling and translation coverage.
